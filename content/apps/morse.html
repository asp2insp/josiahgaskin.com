Morse Code Translator

Encode and decode morse code with audio playback

Morse Code Reference

How to use

  • Encode: Enter regular text and click Translate to convert to morse code
  • Decode: Enter morse code (dots and dashes) with spaces between letters, and click Translate
  • Play Audio: Listen to the morse code as audio beeps (dit and dah sounds)
  • Format: Use dots (.) and dashes (-) for morse code input
