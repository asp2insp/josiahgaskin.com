Last updated 13 September 2026.

This policy covers the personal assistant software I, Josiah Gaskin, write and run for my own use: a private web app and API at `josiahgaskin.com` and its subdomains, a watch app, and a voice assistant on a tabletop display in my home. It exists because Google requires a privacy policy for any app that connects to a Google account, including one whose only user is its author.

## Who this software is for

Me. It is not offered to the public, it has no sign-up, and no one other than me has an account. If you have arrived here from somewhere other than my own Google consent screen, nothing on this page applies to you, because the software does not collect anything from you.

## What it accesses, and why

With my permission, given through Google's OAuth consent screen, the software reads from my own Google account:

- **Google Calendar**, to tell me what is coming up and to answer questions about my schedule.
- **Gmail**, read only, to find and summarise my own messages when I ask.
- **Google Drive, Docs and Sheets**, read only, to look things up in my own documents when I ask.
- **Google Contacts**, read only, to recognise the people I mention.

It never writes to Gmail, Drive or Contacts, and it never sends mail.

## Where the data goes

Requests are served by a server I own and operate. What I ask, and the answers I get, are stored on that server so I can review my own history. Small parts of the Google data involved in a request (for example the text of a calendar event I asked about) are sent to Anthropic's API to produce the assistant's reply, under Anthropic's API terms; Anthropic does not use API data to train its models. Nothing is sold, shared, or shown to anyone else, and there is no advertising.

## Google's Limited Use requirements

Use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. Google user data is used only to provide the assistant's features to the account holder, is not transferred to anyone else except as needed to provide those features, and is not used for advertising.

## Revoking access

Access can be withdrawn at any time from the [Google account permissions page](https://myaccount.google.com/permissions), which invalidates the stored token immediately. Stored history can be deleted by me, since I am the only user and I operate the server.
